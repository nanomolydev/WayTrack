# WayTrack

iOS-планировщик дня как «колба жизни»: вертикальная капсула-таймлайн с постоянными
и активными задачами, циклами, отдыхами и перерывами.

## Что уже есть

* **Постоянные задачи** — неизменные отрезки дня (Завтрак, Прогулка).
* **Активные задачи** — циклы + отдыхи + перерывы через N циклов, задаются конфигом.
* **Обволакивание** — при перетаскивании кусок, заступивший на постоянную задачу,
  переносится за неё вместе с хвостом; делится по циклам/отдыхам, а не целым блоком.
* **Смешивание** — при наложении активных задач всплывает выбор приоритета (два квадрата),
  приоритетная перезадаёт циклы/отдыхи на своей территории; правила стыка — в `Engine.mix`.
* **Регулировка** — панель с «+»/«−», началом, концом и шагом в минутах. Шаг сетки — 1 минута.
* **Вертикальный и горизонтальный** таймлайн, обводка выделенного блока, переименование
  циклов через контекстное меню.
* **Экран «Сейчас»** — текущий и следующий отрезок, убывающее кольцо с остатком минут.
* **Уведомления** на границы всех отрезков.
* **Непредсказуемые задачи** — кнопка фиксирует затраченное время, за неделю копится
  статистика, частые предлагаются в постоянные.

## Структура

```
Sources/WayTrackCore/   чистая логика (Engine, модели) — покрыта тестами
Sources/WayTrack/       SwiftUI-интерфейс
Tests/                  swift test
project.yml             XcodeGen — .xcodeproj не хранится в репозитории
```

## Сборка

CI собирает unsigned `.ipa` на каждый push в `main` и публикует релиз.
Три уровня кеша держат сборку короткой:

1. бинарник XcodeGen (ключ — версия);
2. `.build` SwiftPM по хешу ядра и тестов;
3. `DerivedData` по хешу `Sources/**`, `Resources/**`, `project.yml` —
   при точном совпадении Xcode почти ничего не пересобирает, `restore-keys`
   подтягивает ближайший предыдущий кеш при изменениях.

Локально: `swift test` для ядра, `xcodegen generate && open WayTrack.xcodeproj` для приложения.

## LiveContainer

Постоянная ссылка на источник (обновляется каждым релизом):

```
https://github.com/<OWNER>/<REPO>/releases/latest/download/repo.json
```

Добавьте её в LiveContainer → Sources, и новые сборки будут прилетать обновлением.

## ИИ-планировщик

В приложении есть кнопка ✨ — чат с Claude, который умеет создавать, двигать и менять
задачи. Удаление разрешено только тумблером в настройках.

Запрос идёт не напрямую в Anthropic, а на мост `bridge/waytrack_bridge.py`,
который поднят на сервере рядом с `claude-vpn` (подписка + kzVPN-прокси):

```
POST /chat  Authorization: Bearer <токен>
{"prompt": "...", "model": "claude-sonnet-5", "session": "<id|null>"}
→ {"reply": "...", "session": "...", "sleeps_in": 900}
GET /health → {"awake": true, "quiet_for": 42}
```

Первый запрос будит сессию Claude Code, следующие продолжают её через `--resume`.
Если запросов не было `WAYTRACK_IDLE` секунд (по умолчанию 900), сессия засыпает и
следующее обращение начинает разговор заново — так контекст не тухнет неделями.

Наружу мост отдаёт nginx по HTTPS (`https://outmarin.com/waytrack`), сам порт 8765
слушает только localhost — открытого порта на сервере нет. Без заголовка
`Authorization` мост отвечает 401.

Сервис: `systemctl status waytrack-bridge`, токен и настройки — в `/root/.waytrack-bridge.env`.
Адрес уже прописан в приложении по умолчанию, в ⚙️ Настройках нужно вставить токен
и выбрать модель.
